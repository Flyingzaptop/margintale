# Эволюция с фильтрами режима и фитнесом, нейтральным к тренду

Код: `backtest/evolve2.py`, отчёт: `backtest/evolve2_report.py`, график: `img/evolution_neutral.png`.
Запуск: `cd backtest && python3 evolve2.py --n0 2000 --seed 1 && python3 evolve2_report.py`.

## Что изменилось по сравнению с `03_evolution.md`
* **Новые гены** (проверяются при открытии корзины):
  * ER — эффективность движения (|чистое движение| / сумма |движений|) за 1 ч / 4 ч / 1 день, порог 0.02–0.2:
    торговать только в «пиле»;
  * сессия: Азия 0–7, Лондон 7–12, Нью-Йорк 12–17, вечер 17–24 UTC или любое время;
  * волатильность: ATR / средний ATR за 20 дней ниже 0.7 / 1.0 / 1.5.
* **Фитнес нейтрален к тренду.** Каждая особь торгует двумя счетами с одинаковыми генами — на реальной цене
  и на зеркальной (k / цена). Дети — от средней прибыли двух счетов, поэтому угадывание направления золота
  очков не даёт. Смерть — если слился любой из двух счетов.

## Результаты (2 сида, 2 000 стартовых особей)
Капитал популяции, реальная / зеркальная цена:

| Год | сид 1 | сид 2 |
|---|---|---|
| 2017 | −61% / −60% | −67% / −67% |
| 2018 | −64% / −67% | −57% / −66% |
| 2019 | −80% / −74% | −67% / −44% |
| 2020 | −91% / −83% | −93% / −84% |
| 2021 | −91% / −88% | −85% / −84% |
| 2022 | −81% / −80% | −83% / −79% |
| 2023 | −96% / −94% | −96% / −93% |
| 2024 | −90% / −77% | −82% / −80% |
| 2025 | −34% / −70% | −28% / −70% |
| 2026 | −82% / −52% | −87% / −52% |

* Медианный фитнес положителен только в 32–35% месяцев; в типичный месяц в плюсе 38% особей.
* Потери меньше, чем без фильтров (−60…−90% в год вместо −75…−98%), но ни одного года в плюсе ни в одном мире.

**К чему сошлась популяция** (доля особей в конце):
* фильтр волатильности — 91–92%, фильтр ER — 69–76%;
* сессия Лондон или Нью-Йорк — 78–72%, «любое время» — 11–12%;
* направление «по тренду» (EMA) — 48–53%, чистая сетка без множителя — 8–11%.

Отбор действительно предпочёл торговать реже — только в спокойном рынке, в рабочие часы и по тренду.
Но это снижает частоту катастроф, а не делает ожидание положительным.

**Кандидаты** (3 самых старых выживших каждого прогона, по годам с $1 000): ни у одного сумма
«реальная + зеркальная» не положительна. Лучший по нейтральной метрике — «по тренду, шаг 2 ATR, ×1.6, Лондон,
волатильность < 0.7»: +$6 404 на реальной цене и −$1 116 на зеркальной, т. е. снова в основном рост золота.
Самые старые выжившие родились в 2024–2025 годах: устойчивых долгожителей нет.

## Вывод
Даже когда отбору дали инструменты для поиска «спокойного» рынка и отняли награду за тренд, он не нашёл
сетку/мартингейл с положительным ожиданием на XAUUSD 2017–2026. Найденные фильтры полезны только как
способ проигрывать медленнее. Источника преимущества в самом механизме усреднения нет; следующий шаг, если
продолжать, — искать преимущество отдельно (статистически, без сетки) и только потом выбирать для него исполнение.
